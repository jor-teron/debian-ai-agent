Debian AI Agent

Tiny browser chat agent for Debian (Gemini / ChatGPT / Grok / Claude / DeepSeek). Python only — no heavy installs.

1) One-line install

curl -fsSL https://raw.githubusercontent.com/jor-teron/debian-ai-agent/main/install.sh | bash

2) Or download the script

Prefer to read it first? Download install.sh, then run it yourself.

Download install.sh View on GitHub

After install

  1. Add an API key: nano ~/debian-ai-agent/.env
  2. Restart: systemctl --user restart debian-ai-agent
  3. Open http://127.0.0.1:9191
